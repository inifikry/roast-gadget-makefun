# One-Line Roast: The Gadget You Use Every Day

A single line roasting the robot vacuum I run every day:

> My robot vacuum has a perfect map of my house and still eats the same charging cable every morning, like a Roomba with amnesia.

The joke: the vacuum's whole selling point is that it memorises the layout of the house, yet it still swallows the same phone charger every morning — a machine with a perfect map and no memory. 127 characters, one line.
